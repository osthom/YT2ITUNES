**YT2ITUNES: A YT-DLP Frontend that connects to Apple Music**

YT2ITUNES is a desktop application for MacOS (currently only arm64 architecture) that uses yt-dlp, ffmpeg, and ffprobe to download playlists from youtube and add them to apple music.
